\section{Introducción}
\label{sec:intro}

Este archivo es un ejemplo de cómo escribir en este repositorio.
Cada oración va en su propia línea, porque Git compara línea por línea.
Así, si alguien corrige una palabra, el cambio aparece en una sola línea y no en todo el párrafo.

La radiación de un agujero negro fue descrita por Hawking~\cite{hawking1975particle}.
Para la electrodinámica clásica se puede consultar el texto de Jackson~\cite{jackson1999classical}.

La energía de un oscilador armónico cuántico es
\begin{equation}
  E_n = \hbar\omega\left(n + \frac{1}{2}\right),
  \label{eq:oscilador}
\end{equation}
y en la \cref{sec:methods} se usa la \cref{eq:oscilador} para estimar valores numéricos.
